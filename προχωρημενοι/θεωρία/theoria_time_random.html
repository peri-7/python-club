Θεωρία: οι βιβλιοθήκες time και random

Βιβλιοθήκες

Βιβλιοθήκη ονομάζεται μια συλλογή έτοιμου κώδικα (κυρίως συναρτήσεων) της python.

Για να τις εισάγουμε στα προγράμματα μας, γράφουμε import και μετά το όνομα της βιβλιοθήκης.

Παράδειγμα:

import time
import random

Για να χρησιμοποιήσουμε κάποια συνάρτηση μιας βιβλιοθήκης, γράφουμε πρώτα το όνομα της βιβλιοθήκης, βάζουμε μια τελεία και καλούμε τη συνάρτηση.

Παράδειγμα:

time.sleep()
i

Το import το γράφουμε μία φορά, στην αρχή του προγράμματος.

Η βιβλιοθήκη time

Time ονομάζεται η βιβλιοθήκη που εισάγει χρόνο στα προγράμματα μας.

Έχει δύο βασικές συναρτήσεις.

1

time.time()

Επιστρέφει τον αριθμό δευτερολέπτων που έχει περάσει από τις 12 τα μεσάνυχτα, την 1η Ιανουαρίου του 1970 ! (δεν κάνω πλάκα…)

Παράδειγμα:

start = time.time()

for i in range(10000000):
    x = 5
    x = x + 10

end = time.time()

program_time_in_seconds = end - start

Το παραπάνω πρόγραμμα μετράει τον αριθμό των δευτερολέπτων που χρειάστηκε το for loop.

2

time.sleep()

Παγώνει το πρόγραμμα για τον αριθμό δευτερολέπτων που ζητήσαμε.

Παράδειγμα:

x = 0

while True:
    time.sleep(1)
    x = x + 1
    if x >= 100:
        break

Το παραπάνω πρόγραμμα μετράει 100 δευτερόλεπτα και μετά τερματίζει.

Η βιβλιοθήκη random

Random ονομάζεται η βιβλιοθήκη που εισάγει τυχαιότητα στα προγράμματα μας.

Ακολουθούν οι βασικότερες συναρτήσεις της.

1

random.randint(a, b)

Επιστρέφει έναν τυχαίο ακέραιο από a ως b, με πιθανότητα 1/(b-a+1).

Παράδειγμα:

die = random.randint(1, 6)   #ρίψη δίκαιου ζαριού
2

random.random()

Επιστρέφει έναν τυχαίο δεκαδικό αριθμό από το 0.0 έως το 1.0, αλλά όχι το 1.0

Παράδειγμα:

probability = random.random()

if (probability < 0.2):
    print("low chance of happening")
3

random.uniform(a, b)

Επιστρέφει έναν τυχαίο δεκαδικό αριθμό από το a ως το b.

Παράδειγμα:

probability = random.uniform(0.0, 1.0)

if (probability == 1.0):
    print("It will definitely happen")
4

random.choice()

Επιστρέφει ένα τυχαίο στοιχείο μιας λίστας.

Παράδειγμα:

coin = random.choice(["heads", "tails"])
5

random.shuffle()

Ανακατεύει τυχαία τη σειρά των στοιχείων μιας λίστας.

Παράδειγμα:

cards = ["ace", "king", "queen", "jack"]

random.shuffle(cards)
print(cards)

Έξοδος:

['queen', 'ace', 'king', 'jack']
