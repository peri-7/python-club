## Άσκηση 2

Γράψε ένα πρόγραμμα που ζητάει από τον χρήστη αριθμό λεπτών και εμφανίζει σε
πόσες ώρες και πόσα λεπτά αντιστοιχεί.

```screen title="Παράδειγμα εξόδου"
λεπτά;{{75}}
1 : 15
```

!!! tip "Extra Tip: αλλαγή τύπου δεδομένων"
    Μπορούμε να αλλάξουμε τον τύπο δεδομένων μιας τιμής:

    | Εντολή | Λειτουργία |
    |--------|------------|
    | `str()` | μετατροπή σε string (συμβολοσειρά) |
    | `int()` | μετατροπή σε int (ακέραιο αριθμό) |
    | `float()` | μετατροπή σε float (δεκαδικό αριθμό) |

    ```python title="str()"
    a = 24
    b = "hrs"
    a = str(a) + b
    ```

    ```screen title="Αποτέλεσμα"
    a = "24hrs"
    ```

    ```python title="int()"
    a = 6.7
    print(int(a))
    ```

    ```screen title="Αποτέλεσμα"
    6
    ```

    ```python title="float()"
    a = 5
    a = float(a)
    ```

    ```screen title="Αποτέλεσμα"
    a = 5.0
    ```

## Άσκηση 8

Ένα κατάστημα ζητά τη βοήθειά σας για να φτιάξει τον τιμοκατάλογο των
εκπτώσεων. Σας δίνει την αρχική τιμή ενός προϊόντος και την έκπτωση (ποσοστό στα
εκατό: %). Εσείς πρέπει να εμφανίζετε τη νέα τιμή.

```screen title="Παράδειγμα εξόδου"
τιμή:{{37}}
έκπτωση:{{26}}
νέα τιμή: 27.38
```

!!! tip "Extra Tip: στρογγυλοποίηση"
    Η εντολή `round(αριθμός, αριθμός δεκαδικών ψηφίων)` στρογγυλοποιεί μια τιμή
    στον πλησιέστερο αριθμό με τον ζητούμενο αριθμό δεκαδικών ψηφίων.
    Αν δεν γράψουμε αριθμό δεκαδικών ψηφίων, η `round()` επιλέγει αυτόματα 0
    δεκαδικά ψηφία.

    ```python
    a = 8.78
    a = round(a)
    print(a)
    ```

    ```screen title="Έξοδος"
    9
    ```

    ```python
    a = 9.8878787878
    print(round(a, 2))
    ```

    ```screen title="Έξοδος"
    9.89
    ```

## Άσκηση 12

Σε ένα τραπεζικό σύστημα, κάθε χρήστης δημιουργεί έναν αριθμητικό κωδικό
ασφαλείας για τον λογαριασμό του, δηλαδή έναν συνδυασμό ψηφίων από το 0 έως το 9,
π.χ. 1234.

Γράψτε ένα πρόγραμμα που, με είσοδο το μήκος του κωδικού ενός χρήστη, εμφανίζει

ένας χάκερ για να χακάρει τον συγκεκριμένο κωδικό, αν ο υπολογιστής του μπορεί
να δοκιμάζει 1000 κωδικούς το δευτερόλεπτο.

