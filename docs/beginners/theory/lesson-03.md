## Boolean μεταβλητές

### Τι είναι τα Boolean;

Στον προγραμματισμό, πολλές φορές θέλουμε ο υπολογιστής να παίρνει αποφάσεις:

Αν κάτι είναι αληθινό ➜ κάνε Α<br>
αλλιώς, αν είναι ψεύτικο ➜ κάνε Β.

Για να μπορέσουμε να εκφράσουμε αυτή τη διαφορά ανάμεσα στο αληθινό και το
ψεύτικο, η Python χρησιμοποιεί έναν ειδικό τύπο δεδομένων που ονομάζεται
**Boolean**.

### Ο τύπος δεδομένων bool

Ένας Boolean μπορεί να έχει μόνο δύο τιμές:

```python
True     # Αληθές
False    # Ψευδές
```

!!! warning "Προσοχή"
    Πρέπει το πρώτο γράμμα να είναι κεφαλαίο.

Μπορούμε λοιπόν να δώσουμε σε μια Boolean μεταβλητή την τιμή `True` ή `False`.

Παράδειγμα:

```python
is_sunny = True
is_rainy = False
```

!!! info "Σκέψου το Boolean ως έναν «ανιχνευτή αλήθειας»:"
    - Αν κάτι συμβαίνει, η Python λέει `True`.
    - Αν δεν συμβαίνει, λέει `False`.

??? tip "Ψάξε μόνος σου"
    [docs.python.org — ο τύπος Boolean (bool)](https://docs.python.org/3/library/stdtypes.html#boolean-type-bool)

## Τελεστές σύγκρισης (comparison operators)

Οι συγκριτικοί τελεστές είναι σύμβολα που χρησιμοποιούμε στην Python για να
συγκρίνουμε δύο τιμές (αριθμούς, μεταβλητές, ή ακόμα και λέξεις).

Το αποτέλεσμα της σύγκρισης είναι πάντα Boolean, δηλαδή `True` ή `False`.

### Οι βασικοί συγκριτικοί τελεστές

| Τελεστής | Ανάγνωση στα ελληνικά | Παράδειγμα | Αποτέλεσμα |
|----------|-----------------------|------------|------------|
| `==` | ίσο με | `5 == 5` | `True` |
| `!=` | διάφορο από | `5 != 3` | `True` |
| `>` | μεγαλύτερο από | `10 > 7` | `True` |
| `<` | μικρότερο από | `3 < 2` | `False` |
| `>=` | μεγαλύτερο ή ίσο από | `4 >= 4` | `True` |
| `<=` | μικρότερο ή ίσο από | `2 <= 5` | `True` |

Παραδείγματα:

```python
a = 10
b = 5
print(a > b)
print(a == b)
print(a != b)
print(a <= 10)
```

```screen title="Έξοδος"
True
False
True
True
```

### Ειδική σημείωση για κείμενα (strings)

Στην Python, χρησιμοποιώντας αυτούς τους τελεστές, μπορούμε να συγκρίνουμε και
λέξεις (strings). Η Python τότε θα συγκρίνει τα γράμματα αλφαβητικά
(λεξικογραφικά, δηλαδή ποιο γράμμα εμφανίζεται πρώτο στην αλφάβητο).

Παράδειγμα:

```python
print("apple" == "apple")
print("apple" < "bowl")
print("bowl" > "candy")
```

```screen title="Έξοδος"
True
True
False
```

Δηλαδή `"apple" < "bowl"` επειδή το `a` προηγείται του `b` στο αλφάβητο, ενώ ο
τελεστής `==` θα συγκρίνει αν οι δύο λέξεις είναι ίδιες.

### Αλυσιδωτές συγκρίσεις (chaining comparison operators)

Μπορούμε επίσης στην Python να ελέγχουμε αν μια μεταβλητή βρίσκεται μέσα σε ένα
διάστημα, χρησιμοποιώντας αλυσιδωτές συγκρίσεις.

Παράδειγμα:

```python
x = 5

print(1 < x < 10)
```

```screen title="Έξοδος"
True
```

!!! info ""
    Είναι σαν να ελέγχουμε αν δύο συγκρίσεις ισχύουν ταυτόχρονα, `x > 1` ΚΑΙ
    `x < 10`, δηλαδή αν το `x` ανήκει στο διάστημα ανάμεσα στο 1 και το 10, όπως
    κάνουμε στα μαθηματικά.

??? tip "Ψάξε μόνος σου"
    [docs.python.org — συγκρίσεις (comparisons)](https://docs.python.org/3/library/stdtypes.html#comparisons)

## Λογικοί τελεστές (logical operators)

Οι **λογικοί τελεστές** χρησιμοποιούνται για να **συνδυάζουμε** ή να
**αντιστρέφουμε** συνθήκες (δηλαδή εκφράσεις που δίνουν `True` ή `False`).

Με αυτούς μπορούμε να ελέγξουμε **πολλά πράγματα ταυτόχρονα** και να πάρουμε
μία τελική απάντηση, όταν χρειάζεται να ελέγξουμε πιο περίπλοκες συνθήκες.

### Οι βασικοί λογικοί τελεστές στην Python

| Τελεστής | Ανάγνωση | Περιγραφή | Παράδειγμα | Αποτέλεσμα |
|----------|----------|-----------|------------|------------|
| `and` | και | Επιστρέφει `True` μόνο αν και οι δύο συνθήκες είναι `True` | `x < 10 and x > 0` | `True` αν το `x` είναι μεταξύ 0 και 10 |
| `or` | ή | Επιστρέφει `True` αν τουλάχιστον μία συνθήκη είναι `True` | `x < 0 or x > 100` | `True` αν το `x` είναι έξω από 0–100 |
| `not` | όχι | Αντιστρέφει το αποτέλεσμα: `True` γίνεται `False`, `False` γίνεται `True` | `not(x > 5)` | `True` αν το `x` δεν είναι πάνω από 5 |

Παραδείγματα:

```python
x = 5

print(x > 2 and x < 10)
print(x > 2 or x > 10)
print(not(x > 2 and x < 10))
```

```screen title="Έξοδος"
True
True
False
```

Οι λογικοί τελεστές λειτουργούν όπως η **κοινή λογική** που χρησιμοποιούμε
καθημερινά.

| Κατάσταση στην καθημερινή ζωή | Παράδειγμα στην Python |
|-------------------------------|------------------------|
| Αν **έχω λεφτά** και **είναι ανοιχτό το μαγαζί**, θα αγοράσω τσίχλες. | `if have_money and shop_open:` |
| Αν **είναι Σάββατο** ή **είναι Κυριακή**, δεν έχω σχολείο. | `if day == "Saturday" or day == "Sunday":` |
| Αν **δεν** είμαι άρρωστος, θα πάω στη συναυλία. | `if not sick:` |

Με αυτόν τον τρόπο μπορούμε να εισάγουμε λογική στα προγράμματά μας.

### Οι τρεις τελεστές πιο αναλυτικά

**Ο τελεστής `and`**

| Συνθήκη Α | Συνθήκη Β | Α `and` Β |
|-----------|-----------|-----------|
| `True` | `True` | `True` |
| `True` | `False` | `False` |
| `False` | `True` | `False` |
| `False` | `False` | `False` |

Επιστρέφει `True` **μόνο** αν και οι δύο συνθήκες είναι `True`. Αν έστω μία
είναι `False`, το αποτέλεσμα είναι `False`.

**Ο τελεστής `or`**

| Συνθήκη Α | Συνθήκη Β | Α `or` Β |
|-----------|-----------|----------|
| `True` | `True` | `True` |
| `True` | `False` | `True` |
| `False` | `True` | `True` |
| `False` | `False` | `False` |

Επιστρέφει `True` αν **τουλάχιστον μία** συνθήκη είναι `True`. Μόνο αν **όλες**
είναι `False`, τότε το αποτέλεσμα είναι `False`.

**Ο τελεστής `not`**

| Συνθήκη Α | `not` Α |
|-----------|---------|
| `True` | `False` |
| `False` | `True` |

Αντιστρέφει το αποτέλεσμα μιας συνθήκης: `not True` → `False`,
`not False` → `True`.

### Συνδυασμός λογικών τελεστών

Μπορούμε να συνδυάσουμε περισσότερους από έναν λογικούς τελεστές μέσα στην ίδια
συνθήκη.

Παράδειγμα:

```python
age = 14
has_ticket = True
print((age >= 12 and age <= 17) and has_ticket)
```

```screen title="Έξοδος"
True
```

Παράδειγμα:

```python
day = "Saturday"
good_weather = True

print((day == "Saturday" or day == "Sunday") and good_weather)
```

```screen title="Έξοδος"
True
```

??? tip "Ψάξε μόνος σου"
    [docs.python.org — λογικοί τελεστές (and, or, not)](https://docs.python.org/3/library/stdtypes.html#boolean-operations-and-or-not)

## Οι εντολές if, elif, else

Η Python μας επιτρέπει να παίρνουμε αποφάσεις με τις εντολές `if`, `elif` και
`else`. Αυτές ελέγχουν συνθήκες (που δίνουν `True` ή `False`) και εκτελούν
διαφορετικό κώδικα ανάλογα με το αποτέλεσμα.

### Η εντολή if

Η εντολή `if` εκτελεί ένα μπλοκ εντολών μόνο αν μια συνθήκη είναι αληθής
(`True`). Αν η συνθήκη είναι ψευδής (`False`), ο υπολογιστής απλώς προσπερνά
αυτό το μπλοκ.

```python title="Σύνταξη"
if <συνθήκη>:
    # εντολές που θα εκτελεστούν αν η συνθήκη είναι True
```

!!! warning "Προσοχή στην εσοχή (indentation)"
    Όλες οι εντολές που ανήκουν στο `if` πρέπει να γράφονται πιο μέσα.

Παράδειγμα:

```python
a = 3
b = 200
if b > a:
    print("b είναι μεγαλύτερο από a")
```

```screen title="Έξοδος"
b είναι μεγαλύτερο από a
```

Εδώ η συνθήκη `b > a` είναι `True`, οπότε η Python εκτελεί την `print()`. Αν δεν
ήταν, θα αγνοούσε το μπλοκ του `if` και δεν θα εμφανιζόταν τίποτα στην έξοδο.

!!! warning "Προσοχή"
    Αν δεν είχαμε κρατήσει την εσοχή στο `print` κάτω από το `if`, θα παίρναμε
    σφάλμα, καθώς δεν θα υπήρχε κώδικας να εκτελεστεί αν η συνθήκη είναι `True`.

```python
a = 3
b = 200
if b > a:
print("b είναι μεγαλύτερο από a")
```

```screen title="Έξοδος"
  File "main.py", line 4
    print("b είναι μεγαλύτερο από a")
    ^^^^^
IndentationError: expected an indented block after 'if' statement on line 3
```

Αν θέλουμε να εκτελεστούν πολλές εντολές όταν μία συνθήκη είναι αληθής, πρέπει
να προσέξουμε να κρατήσουμε την ίδια εσοχή για όλες τις εντολές.

Παράδειγμα:

=== ":material-check: Σωστή σύνταξη"

    ```python
    age = 20
    if age >= 18:
        print("Είσαι ενήλικας")
        print("Μπορείς να ψηφίσεις")
    ```

=== ":material-close: Λανθασμένη σύνταξη"

    ```python
    age = 20
    if age >= 18:
        print("Είσαι ενήλικας")
    print("Μπορείς να ψηφίσεις")
    ```

Στη δεύτερη περίπτωση, μέσα στο `if` ανήκει μόνο το πρώτο `print`!

### Η εντολή elif

Αν θέλουμε να ελέγξουμε περισσότερες από μία συνθήκες, μπορούμε να
χρησιμοποιήσουμε `elif` (προέρχεται από το *else if*).

Η Python θα ελέγξει τις συνθήκες μία προς μία, από πάνω προς τα κάτω:

- Μόλις βρει μία που είναι `True`,
- εκτελεί το αντίστοιχο μπλοκ,
- και αγνοεί τα υπόλοιπα.

```python title="Σύνταξη"
if <συνθήκη1>:
    # εντολές αν η συνθήκη1 είναι True
elif <συνθήκη2>:
    # εντολές αν η συνθήκη2 είναι True
elif <συνθήκη3>:
    # εντολές αν η συνθήκη3 είναι True
...
```

Μπορούμε να βάζουμε όσες `elif` συνθήκες χρειάζεται η εφαρμογή μας, κρατώντας
αυτή τη σύνταξη.

Παράδειγμα:

```python
a = 33
b = 33

if b > a:
    print("b είναι μεγαλύτερο από a")
elif a == b:
    print("a και b είναι ίσα")
```

```screen title="Έξοδος"
a και b είναι ίσα
```

Η πρώτη συνθήκη `b > a` είναι `False`, οπότε η Python ελέγχει τη δεύτερη
(`a == b`), που είναι `True`. Αμέσως εκτελεί το `print()` και σταματάει τον
έλεγχο.

!!! warning "Προσοχή"
    Αν περισσότερες από μία συνθήκες είναι `True`, τότε η Python θα εκτελέσει
    τον κώδικα της πρώτης συνθήκης που θα συναντήσει `True`, κοιτώντας από πάνω
    προς τα κάτω.

Παράδειγμα:

```python
x = 10

if x > 1:
    print("hello1")
elif x > 2:
    print("hello2")
```

```screen title="Έξοδος"
hello1
```

Όπως βλέπουμε στον παραπάνω κώδικα, παρότι και η δεύτερη συνθήκη `x > 2` είναι
`True`, ο κώδικάς της θα προσπεραστεί και δεν θα εκτελεστεί ποτέ. Για να
εκτελεστεί, θα έπρεπε να χρησιμοποιήσουμε δύο `if`.

Χρησιμοποιούμε `elif` όταν ελέγχουμε αμοιβαία αποκλειόμενα γεγονότα, οπότε
είναι `True` μόνο μία συνθήκη!

### Η εντολή else

Η `else` εκτελείται όταν καμία από τις προηγούμενες συνθήκες δεν είναι `True`.

Είναι το «όλα τα υπόλοιπα» ή «σε κάθε άλλη περίπτωση».

```python title="Σύνταξη"
if <συνθήκη1>:
    # εντολές αν η συνθήκη1 είναι True
elif <συνθήκη2>:
    # εντολές αν η συνθήκη2 είναι True
else:
    # εντολές αν όλες οι παραπάνω είναι False
```

Παράδειγμα:

```python
a = 200
b = 33

if b > a:
    print("b είναι μεγαλύτερο από a")
elif a == b:
    print("a και b είναι ίσα")
else:
    print("a είναι μεγαλύτερο από b")
```

```screen title="Έξοδος"
a είναι μεγαλύτερο από b
```

!!! info ""
    Εδώ καμία από τις δύο πρώτες συνθήκες δεν είναι αληθής, οπότε η Python
    φτάνει στο `else` και εκτελεί τις εντολές του.

Μπορούμε να μη χρησιμοποιήσουμε την ενδιάμεση `elif` αν δεν τη χρειαζόμαστε.

??? tip "Ψάξε μόνος σου"
    [docs.python.org — η εντολή if (tutorial)](https://docs.python.org/3/tutorial/controlflow.html#if-statements)

## Σύντομη μορφή if (short hand if)

Αν η εντολή που θέλουμε να εκτελέσουμε είναι μία μόνο γραμμή, μπορούμε να
γράψουμε το `if` σε μία γραμμή.

```python title="Σύνταξη"
if <συνθήκη>: <εντολή>
```

Παράδειγμα:

```python
a = 200
b = 33
if a > b: print("a είναι μεγαλύτερο από b")
```

```screen title="Έξοδος"
a είναι μεγαλύτερο από b
```

### Σύντομη μορφή if...else (short hand if...else)

Μπορούμε επίσης να γράψουμε `if` και `else` στην ίδια γραμμή, όταν είναι απλές
εντολές.

```python title="Σύνταξη"
<εντολή-if> if <συνθήκη> else <εντολή-else>
```

Παράδειγμα:

```python
a = 2
b = 330
print("A") if a > b else print("B")
```

```screen title="Έξοδος"
B
```

Αυτός ο τρόπος λέγεται *conditional expression* και είναι χρήσιμος για απλά
«ναι ή όχι» αποτελέσματα.

??? tip "Ψάξε μόνος σου"
    [docs.python.org — conditional expressions](https://docs.python.org/3/reference/expressions.html#conditional-expressions)

## Εμφωλευμένα if (nested if)

Μπορούμε να βάλουμε ένα `if` μέσα σε ένα άλλο `if`. Αυτό λέγεται εμφωλευμένο if
(nested if) και μας επιτρέπει πιο σύνθετες αποφάσεις.

```python title="Σύνταξη"
if <συνθήκη1>:
    <εντολή1>
    if <συνθήκη2>:
        <εντολή2>
```

Παράδειγμα:

```python
x = 41

if x > 10:
    print("Πάνω από 10")
    if x > 20:
        print("Επίσης πάνω από 20!")
    else:
        print("Αλλά όχι πάνω από 20.")
```

```screen title="Έξοδος"
Πάνω από 10
Επίσης πάνω από 20!
```

Εδώ έχουμε ένα `if` μέσα σε ένα άλλο. Η Python πρώτα ελέγχει αν `x > 10`, και
μέσα σε αυτό το μπλοκ ελέγχει αν `x > 20`.

## Συνοπτικός πίνακας με όσα είδαμε ως τώρα

| Εντολή | Ρόλος | Εκτελείται όταν... |
|--------|-------|--------------------|
| `if` | Αρχικός έλεγχος | Η συνθήκη είναι `True` |
| `elif` | Εναλλακτικός έλεγχος | Η προηγούμενη ήταν `False` και αυτή είναι `True` |
| `else` | Τελική περίπτωση | Όλες οι προηγούμενες ήταν `False` |
| nested if | Εμφωλευμένος έλεγχος | Μια δεύτερη απόφαση μέσα σε άλλη |
| short hand | Σύντομη μορφή | Όταν έχουμε μικρές, μονογραμμικές εντολές |

## Η εντολή match

Η εντολή `match` στην Python χρησιμοποιείται για να επιλέξουμε ποια από πολλές
επιλογές θα εκτελεστεί, με βάση την τιμή μιας έκφρασης.

Αντί να γράφουμε πολλές `if…elif…else`, μπορούμε να χρησιμοποιήσουμε `match` για
πιο καθαρό και οργανωμένο κώδικα.

```python title="Σύνταξη"
match <έκφραση>:
    case <τιμή1>:
        # μπλοκ εντολών αν έκφραση == τιμή1
    case <τιμή2>:
        # μπλοκ εντολών αν έκφραση == τιμή2
    case _:
        # μπλοκ εντολών αν καμία από τις παραπάνω δεν ταιριάζει
```

Η `_` χρησιμοποιείται ως «προεπιλεγμένη περίπτωση» (default) αν δεν ταιριάξει
καμία από τις άλλες.

### Παραδείγματα

Παράδειγμα 1:

```python
day = 4
match day:
    case 1:
        print("Monday")
    case 2:
        print("Tuesday")
    case 3:
        print("Wednesday")
    case 4:
        print("Thursday")
    case 5:
        print("Friday")
    case 6:
        print("Saturday")
    case 7:
        print("Sunday")
```

```screen title="Έξοδος"
Thursday
```

Παράδειγμα 2 (συνδυασμός τιμών):

```python
day = 4
match day:
    case 1 | 2 | 3 | 4 | 5:
        print("Today is a weekday")
    case 6 | 7:
        print("I love weekends!")
```

```screen title="Έξοδος"
Today is a weekday
```

!!! info ""
    Εδώ ο τελεστής `|` είναι σαν τον τελεστή `or`.

Παράδειγμα 3 (guard στο case):

```python
month = 5
day = 4
match day:
    case 1 | 2 | 3 | 4 | 5 if month == 4:
        print("A weekday in April")
    case 1 | 2 | 3 | 4 | 5 if month == 5:
        print("A weekday in May")
    case _:
        print("No match")
```

```screen title="Έξοδος"
A weekday in May
```

!!! warning "Προσοχή"
    Όπως είπαμε ήδη για τα `elif`, μόλις βρεθεί το πρώτο match θα εκτελεστεί και
    οι υπόλοιπες περιπτώσεις θα προσπεραστούν! Χρειάζεται λοιπόν προσοχή στη
    σειρά που τοποθετούμε τις συνθήκες.

!!! info "Σκέψου το έτσι"
    Σκέψου την εντολή `match` σαν έναν μεγάλο διακόπτη επιλογών: ελέγχει την
    τιμή της έκφρασης μία φορά και «πηδάει» κατευθείαν στην κατάλληλη επιλογή.

??? tip "Ψάξε μόνος σου"
    [docs.python.org — η εντολή match (tutorial)](https://docs.python.org/3/tutorial/controlflow.html#match-statements)
