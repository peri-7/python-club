## Είσοδος – έξοδος – μεταβλητές

### Εμφάνιση τιμών στην οθόνη — `print()`

- Εμφανίζει στην οθόνη αριθμητικές και αλφαριθμητικές σταθερές, τιμές
  μεταβλητών και πολλά ακόμα.
- Αν θέλουμε να εμφανιστούν περισσότερες από μία τιμές, τότε τις χωρίζουμε με
  κόμματα.

```python title="Παραδείγματα"
print('Pythonies')

year = 2016
print('Το σωτήριον έτος', year)
```

- Αν δεν θέλουμε να αλλάξει η γραμμή μετά την εμφάνιση ενός μηνύματος
  (προκαθορισμένη συμπεριφορά), τροποποιούμε την παράμετρο `end`.
- Αν δεν θέλουμε να εμφανίζεται ένα κενό ανάμεσα στις τιμές που τυπώνονται
  (προκαθορισμένη συμπεριφορά), τροποποιούμε την παράμετρο `sep`.

```python title="Παραδείγματα"
print("Συνεχίζονται", end="...")   # δεν αλλάζει γραμμή
print(year - 2, year, sep=":")     # τυπώνει 2014:2016
```

### Μεταβλητές

**Λειτουργία:** ανάθεση ονομάτων σε τιμές.

- Αναθέτουμε σε μια τιμή ένα όνομα με το σύμβολο `=`.

```python title="Παραδείγματα"
weight = 75
name = 'Μάνος'
```

### Είσοδος τιμών από τον χρήστη — `input()`

- Επιστρέφει μια ==αλφαριθμητική== τιμή: το κείμενο που πληκτρολογήθηκε από τον
  χρήστη.
- Αν θέλουμε να μετατρέψουμε την αλφαριθμητική τιμή που επιστρέφεται σε ακέραιο
  ή πραγματικό αριθμό, χρησιμοποιούμε τις `int()`, `float()` κλπ.
- Προαιρετική παράμετρος είναι ένα μήνυμα που θα εμφανιστεί στην οθόνη κατά την
  εκτέλεση της `input()`.

```python title="Παραδείγματα"
name = input("Πώς σε λένε;")
age = int(input())
mesos_oros = float(input("Δώσε μέσο όρο"))
```

## Πράξεις

### Αριθμητικές πράξεις

| Πράξη | Τελεστής |
|-------|----------|
| Πρόσθεση | `+` |
| Αφαίρεση | `-` |
| Πολλαπλασιασμός | `*` |
| Διαίρεση | `/` |
| Ακέραιο πηλίκο | `//` |
| Υπόλοιπο διαίρεσης | `%` |
| Ύψωση σε δύναμη | `**` |

- Η σειρά με την οποία εκτελούνται οι πράξεις είναι ανάλογη των μαθηματικών:
  πρώτα οι δυνάμεις, μετά ο πολλαπλασιασμός και η διαίρεση, και στο τέλος η
  πρόσθεση και η αφαίρεση.
- Για να αλλάξουμε τη σειρά εκτέλεσης των πράξεων χρησιμοποιούμε παρενθέσεις.

| Έκφραση | Τιμή |
|---------|------|
| `46 // 9` | `5` |
| `40 % 9` | `4` |
| `2 ** 3` | `8` |
| `4 * 5 // 8` (δηλαδή `20 // 8`) | `2` |

### Συγκρίσεις

| Σύγκριση | Τελεστής |
|----------|----------|
| Μεγαλύτερο | `>` |
| Μεγαλύτερο ή ίσο | `>=` |
| Μικρότερο | `<` |
| Μικρότερο ή ίσο | `<=` |
| Ίσο | `==` |
| Διάφορο | `!=` |

- Το αποτέλεσμα μιας σύγκρισης είναι η τιμή `True` (Αληθής) ή `False` (Ψευδής).
- Οι εκφράσεις που παίρνουν τέτοιες τιμές ονομάζονται **λογικές εκφράσεις** ή
  **συνθήκες**.
- Για να ελέγξουμε αν δύο τιμές είναι ίσες χρησιμοποιούμε το σύμβολο του διπλού
  ίσον `==`. Το σύμβολο `=` χρησιμοποιείται για ανάθεση τιμών.

### Λογικές πράξεις

| Λογική πράξη | Τελεστής |
|--------------|----------|
| ΚΑΙ | `and` |
| Ή | `or` |
| ΟΧΙ | `not` |

- Το λογικό **ΟΧΙ** (αντιστροφή) χρησιμοποιείται σε μια λογική πρόταση και
  αντιστρέφει την τιμή της.
- Το λογικό **ΚΑΙ** χρησιμοποιείται για τη σύζευξη δύο λογικών προτάσεων. Για να
  είναι Αληθής η σύνθετη πρόταση που σχηματίζεται πρέπει να είναι αληθείς
  ==και οι δύο== συζευγμένες προτάσεις.
- Το λογικό **Ή** χρησιμοποιείται για τη διάζευξη δύο λογικών προτάσεων. Για να
  είναι Αληθής η σύνθετη πρόταση που σχηματίζεται αρκεί να είναι αληθής
  ==οποιαδήποτε== από τις δύο διαζευγμένες προτάσεις.

```python title="Παραδείγματα"
grade > 0 and grade <= 20
day == "Σάββατο" or day == "Κυριακή"
not (number > 0)
```

- `grade > 0 and grade <= 20` — ισχύει (`True`) μόνο όταν η `grade` έχει τιμή στο
  διάστημα (0, 20].
- `day == "Σάββατο" or day == "Κυριακή"` — ισχύει είτε όταν η `day` έχει την τιμή
  `"Σάββατο"`, είτε την τιμή `"Κυριακή"`.
- `not (number > 0)` — ισχύει όταν η `number` δεν είναι μεγαλύτερη του μηδενός.

## Δομή Επιλογής

### Έλεγχος μιας περίπτωσης — `if`

- Η `if` συνοδεύεται από μια συνθήκη η οποία ελέγχεται κατά την εκτέλεση του
  προγράμματος και μπορεί να είναι αληθής (`True`) ή ψευδής (`False`).
- Οι εντολές που ακολουθούν την `if` είναι στοιχισμένες δεξιότερα. Η στοίχιση
  υποδηλώνει ότι αυτές οι εντολές θα εκτελεστούν μόνο αν η αντίστοιχη συνθήκη
  είναι αληθής.
- Η συνθήκη της `if` ακολουθείται από το σύμβολο `:`

```python title="Παραδείγματα"
if num > 0:
    print("Θετικός αριθμός")

if word == "Sesame":
    print("Η πόρτα άνοιξε")
```

### Επιλογή ανάμεσα σε δύο περιπτώσεις — `else`

- Η `else` χρησιμοποιείται μόνο σε συνδυασμό με την `if` (και την `elif`
  παρακάτω) και περιγράφει τις εντολές που θα εκτελεστούν όταν η συνθήκη της
  `if` είναι ψευδής.
- Οι εντολές που ακολουθούν την `else` είναι στοιχισμένες δεξιότερα.
- Η `else` ακολουθείται από το σύμβολο `:`

```python title="Παράδειγμα"
if day == "Κυριακή":
    print("Ώρα για ξεκούραση")
else:
    print("Ώρα για δουλειά")
```

### Επιλογή ανάμεσα σε πολλαπλές περιπτώσεις — `elif`

- Η `elif` χρησιμοποιείται μόνο σε συνδυασμό με την `if`.
- Όπως και η `if`, όταν η συνθήκη που εξετάζει είναι Αληθής εκτελεί ένα σύνολο
  εντολών.
- Οι εντολές που ακολουθούν την `elif` είναι στοιχισμένες δεξιότερα.
- Η συνθήκη της `elif` ακολουθείται από το σύμβολο `:`
- Για να εξεταστεί η συνθήκη μιας `elif` θα πρέπει όλες οι προηγούμενες συνθήκες
  που εξετάστηκαν να είναι ψευδείς.
- Όταν η συνθήκη μιας `elif` είναι αληθής, τότε οι συνθήκες που ακολουθούν
  ==δεν εξετάζονται==.
- Προαιρετικά μπορούμε να χρησιμοποιήσουμε στο τέλος των περιπτώσεων την εντολή
  `else`. Οι εντολές της θα εκτελεστούν όταν καμία από τις προηγούμενες
  περιπτώσεις δεν ισχύει.

```python title="Παράδειγμα"
if number == 6:
    print("Σάββατο")
elif number == 7:
    print("Κυριακή")
else:
    print("Καθημερινή")
```

!!! warning "Προσοχή στη στοίχιση"
    Η `elif` στοιχίζεται ==ακριβώς κάτω από την `if`==, όχι πιο δεξιά. Αν τη
    στοιχίσεις δεξιότερα, η Python σταματάει με `SyntaxError`.

### Η εντολή `match`

Η εντολή `match` χρησιμοποιείται για να επιλέξουμε **ποια από πολλές επιλογές**
θα εκτελεστεί, με βάση την τιμή μιας έκφρασης.

Αντί να γράφουμε πολλές `if...elif...else`, μπορούμε να χρησιμοποιήσουμε `match`
για πιο καθαρό και οργανωμένο κώδικα.

```python title="Σύνταξη"
match <έκφραση>:
    case <τιμή1>:
        # μπλοκ εντολών αν έκφραση == τιμή1
    case <τιμή2>:
        # μπλοκ εντολών αν έκφραση == τιμή2
    case _:
        # μπλοκ εντολών αν καμία από τις παραπάνω δεν ταιριάζει
```

Η `_` χρησιμοποιείται ως «προεπιλεγμένη περίπτωση» (default) αν δεν γίνει κανένα
match.

!!! warning "Προσοχή"
    Όπως είπαμε ήδη για τα `elif`, μόλις βρεθεί το πρώτο match θα εκτελεστεί και
    οι υπόλοιπες περιπτώσεις θα προσπεραστούν! Χρειάζεται λοιπόν προσοχή στη
    σειρά που τοποθετούμε τις συνθήκες.

## Δομή Επανάληψης

### Επανάληψη υπό συνθήκη — `while`

- Ελέγχει μια συνθήκη κι επαναλαμβάνει ένα σύνολο εντολών, όσο η συνθήκη
  παραμένει Αληθής (`True`).
- Οι εντολές που ακολουθούν την `while` είναι στοιχισμένες δεξιότερα. Η στοίχιση
  υποδηλώνει ποιες εντολές θα εκτελεστούν επαναληπτικά.
- Η συνθήκη της `while` ακολουθείται από το σύμβολο `:`

```python title="Παράδειγμα"
import time

count = 10
while count > 0:
    time.sleep(1)
    count = count - 1
print("Λήξη αντίστροφης μέτρησης")
```

### Άμεσος τερματισμός επανάληψης — `break`

- Χρησιμοποιείται με μέτρο. Οι πολλές εντολές `break` μπορεί να κάνουν τον
  κώδικα του προγράμματος δυσνόητο.

```python title="Παράδειγμα"
while True:
    print("Δώσε βαθμό από 1 μέχρι 20")
    grade = int(input())
    if grade < 0 or grade > 20:
        print("Λάθος δεδομένα")
    else:
        break
```

### Η συνάρτηση `range()`

Η `range()` δημιουργεί ακολουθίες αριθμών, σε ένα εύρος τιμών.

Εάν δεν ορίσουμε την αρχή του εύρους τιμών, αυτόματα η Python θα ξεκινήσει από
το `0` και θα φτάσει μέχρι τον αριθμό που δώσουμε μέσα στο `range`, αυξάνοντας
κατά 1 — εκτός αν δώσουμε διαφορετικές οδηγίες, όπως θα δούμε παρακάτω.

```python title="Σύνταξη"
range(αρχή, τέλος, βήμα αύξησης)
```

#### Default (αυτόματη) χρήση

Στην αυτόματη χρήση χρειάζεται να προσδιορίσουμε μονάχα την τελική τιμή, που θα
είναι σε αυτή την περίπτωση και ο αριθμός επαναλήψεων.

```python
for x in range(6):
    print(x)
```

```title="Αποτέλεσμα"
0
1
2
3
4
5
```

!!! note "Παρατήρηση"
    Όπως βλέπουμε στο παραπάνω παράδειγμα, το `range(6)` θα μας δώσει αριθμούς
    από το `0` μέχρι το `5` και ==όχι το `6`==, δηλαδή έναν αριθμό χαμηλότερα
    από αυτόν που δηλώσαμε!

    Εάν το σκεφτούμε περισσότερο, αυτό βγάζει νόημα: με το `range(6)` θέλω να
    δηλώσω πως κάτι είναι να εκτελεστεί έξι φορές, και άρα αφού ξεκινάμε από τον
    αριθμό `0` θα σταματήσουμε στον αριθμό `5` — δηλαδή μετά από 6 αριθμούς!

#### Ορισμός αρχικής τιμής

Μπορούμε, αντί να το αφήνουμε αυτόματα να ξεκινάει από το `0`, να ορίσουμε την
τιμή με την οποία θέλουμε να ξεκινάει το `range()`. Αυτό γίνεται βάζοντας στην
αρχή του `range()` την αρχική τιμή:

```python
for x in range(2, 6):
    print(x)
```

```title="Αποτέλεσμα"
2
3
4
5
```

Εδώ βλέπουμε πως το `range()` μας έδωσε αριθμούς ξεκινώντας από την αρχική τιμή
`2` και φτάνοντας έως έναν αριθμό μικρότερο της τελικής τιμής `6`, το `5`.

#### Ορισμός βήματος αύξησης

Τέλος, μπορούμε να καθορίσουμε συγκεκριμένο βήμα αύξησης σε κάθε επανάληψη, που
είναι διαφορετικό της αύξησης κατά 1 (η αυτόματη επιλογή). Για να το κάνουμε
αυτό αρκεί μετά την τελική τιμή να δηλώσουμε το επιθυμητό βήμα αύξησης.

```python
for x in range(2, 30, 3):
    print(x)
```

```title="Αποτέλεσμα"
2
5
8
11
14
17
20
23
26
29
```

Εδώ βλέπουμε πως οι αριθμοί που επιστρέφει η `range()` ξεκινούν από την αρχική
τιμή `2`, φτάνουν έως την τελική τιμή `30` χωρίς να την ξεπερνούν, αλλά
αυξάνονται όχι κατά 1 αλλά κατά 3, όπως δηλώσαμε μέσα στο `range()`.

## Βιβλιοθήκες

### Εισαγωγή βιβλιοθήκης στο πρόγραμμα — `import`

- Κάθε βιβλιοθήκη γίνεται `import` μία φορά στο πρόγραμμα.
- Για να χρησιμοποιήσουμε τμήματα της βιβλιοθήκης γράφουμε το όνομα της
  βιβλιοθήκης, τελεία `.` και το όνομα του τμήματος που θέλουμε.

```python title="Παραδείγματα"
import random
random.randint(1, 100)

import time
time.sleep(10)
```
