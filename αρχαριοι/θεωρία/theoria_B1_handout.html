Θεωρία: output, μεταβλητές, πράξεις, input

Πρόγραμμα

Πρόγραμμα ονομάζουμε μια σειρά από εντολές που εκτελούνται μία-μία από τον υπολογιστή.

Στην python, κάθε εντολή βρίσκεται σε άλλη γραμμή. Πηγαίνουμε στην κάτω γραμμή πατώντας Enter.

Έξοδος (output)

Η εντολή print εμφανίζει κείμενο στην οθόνη.

Σύνταξη:

Τύποι δεδομένων της python που μπορούμε να εμφανίσουμε με την print:

  1. 1
    κείμενο (string) - πάντα μέσα σε εισαγωγικά (μονά ή διπλά)
  2. 2
    αριθμός (int ή float) - πάντα χωρίς εισαγωγικά!
    int - ακέραιος αριθμός:
    float - δεκαδικός αριθμός:
i

Η εντολή print μας πηγαίνει στην επόμενη γραμμή.

Μεταβλητές (variables)

Πολύ συχνά θέλουμε να αποθηκεύσουμε κάποια τιμή. Σε αυτό μας βοηθούν οι μεταβλητές. Οι μεταβλητές αντιστοιχίζουν ένα όνομα σε μια τιμή. Η αντιστοίχιση γίνεται με το σύμβολο = .

Σύνταξη:

Η τιμή τους μπορεί να αλλάξει.

Σε κάθε σημείο του προγράμματος, η τιμή μιας μεταβλητής κρατάει την τελευταία τιμή που αντιστοιχίστηκε στο όνομα.

Μπορούμε να εκτυπώσουμε την τιμή μιας μεταβλητής, γράφοντας το όνομα της χωρίς εισαγωγικά.

Απλές πράξεις

Τι άλλο μπορούμε να κάνουμε στην print;

!

Προσοχή: όταν έχουμε δεδομένα τύπου string, ο τελεστης (δηλαδή το σύμβολο) + ενώνει τα strings μεταξύ τους.

Είσοδος (input)

Συχνά, το πρόγραμμα μας χρειάζεται κάποιο δεδομένο από τον χρήστη. Mε την εντολή input(), του ζητάμε να το γράψει με το πληκτρολόγιο.

Το πρόγραμμα μας αποθηκεύει την πληροφορία σε μία μεταβλητή.

Μπορούμε να του εμφανίσουμε ένα string για να του πούμε τι πληροφορία θέλουμε να μας δώσει, μέσα στην παρένθεση

Σύνταξη:
Παράδειγμα:

Το μήνυμα “Πώς σε λένε;” εμφανίζεται στον χρήστη. Το κείμενο που θα πληκτρολογήσει ο χρήστης αποθηκεύεται στη μεταβλητή name ως string.

!

Προσοχή:

Ένα string μπορεί να περιέχει οποιοδήποτε χαρακτήρα π.χ. ένα κενό (space) ή έναν αριθμό. Η απάντηση του χρήστη αποθηκεύεται πάντα ως string.

Αν ξέρουμε ότι η απάντηση θα είναι αριθμός και θέλουμε να τη χρησιμοποιήσουμε σε πράξεις:

Πρέπει να τη μετατρέψουμε σε αριθμό μορφής int (ακέραιο αριθμό) ή float (δεκαδικό αριθμό).
