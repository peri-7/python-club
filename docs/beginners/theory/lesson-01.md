## Πρόγραμμα

**Πρόγραμμα** ονομάζουμε μια σειρά από εντολές που εκτελούνται μία-μία από τον
υπολογιστή.

Στην python, κάθε εντολή βρίσκεται σε άλλη γραμμή. Πηγαίνουμε στην κάτω γραμμή
πατώντας ++enter++.

## Έξοδος (output)

Η εντολή `print` εμφανίζει κείμενο στην οθόνη.

```python title="Σύνταξη"
print("κείμενο")
```

Τύποι δεδομένων της python που μπορούμε να εμφανίσουμε με την `print`:

**1. κείμενο (string)** — ==πάντα μέσα σε εισαγωγικά (μονά ή διπλά)==

```python
print('Hello world!')
print("Παίζω σκάκι")
```

**2. αριθμός (int ή float)** — ==πάντα χωρίς εισαγωγικά!==

```python title="int — ακέραιος αριθμός"
print(2026)
```

```python title="float — δεκαδικός αριθμός"
print(3.14)
```

!!! info
    Η εντολή `print` μας πηγαίνει στην επόμενη γραμμή.

??? tip "Ψάξε μόνος σου"
    Η `print` στην επίσημη τεκμηρίωση:
    [docs.python.org — print()](https://docs.python.org/3/library/functions.html#print)

## Μεταβλητές (variables)

Πολύ συχνά θέλουμε να αποθηκεύσουμε κάποια τιμή. Σε αυτό μας βοηθούν οι
μεταβλητές. Οι μεταβλητές αντιστοιχίζουν ένα **όνομα** σε μια **τιμή**.
Η αντιστοίχιση γίνεται με το σύμβολο `=`.

```python title="Σύνταξη"
name = "Peter Parker"
age = 17
```

Η τιμή τους μπορεί να αλλάξει.

```python
name = "Peter Parker"
age = 17
age = 18
```

Σε κάθε σημείο του προγράμματος, η τιμή μιας μεταβλητής κρατάει την **τελευταία**
τιμή που αντιστοιχίστηκε στο όνομα.

Μπορούμε να εκτυπώσουμε την τιμή μιας μεταβλητής, γράφοντας το όνομά της
==χωρίς εισαγωγικά.==

```python
name = "Peter Parker"
age = 17
print(age)
```

## Απλές πράξεις

| Τελεστής | Λειτουργία | Παράδειγμα | Αποτέλεσμα |
|----------|------------|------------|------------|
| `+` | Πρόσθεση | `10 + 4` | `14` |
| `-` | Αφαίρεση | `10 - 4` | `6` |
| `*` | Πολλαπλασιασμός | `10 * 4` | `40` |
| `/` | Διαίρεση (με δεκαδικά) | `10 / 4` | `2.5` |

## Τι άλλο μπορούμε να κάνουμε στην print;

Μπορούμε να εμφανίσουμε **πολλά πράγματα μαζί**, χωρίζοντάς τα με κόμμα:

```python
name = "Peter Parker"
print(name, "is spiderman")
```

```title="Αποτέλεσμα"
Peter Parker is spiderman
```

Μπορούμε να συνδυάσουμε κείμενο και πράξεις:

```python
print("6*7 =", 6*7)
```

```title="Αποτέλεσμα"
6*7 = 42
```

Μπορούμε να κάνουμε πράξεις μέσα στην `print`:

```python
print(6+7)
```

```title="Αποτέλεσμα"
13
```

```python
print("spider"+"man")
```

```title="Αποτέλεσμα"
spiderman
```

!!! warning "Προσοχή"
    Όταν έχουμε δεδομένα τύπου **string**, ο τελεστής (δηλαδή το σύμβολο) `+`
    **ενώνει** τα strings μεταξύ τους.

## Είσοδος (input)

Συχνά, το πρόγραμμά μας χρειάζεται κάποιο δεδομένο από τον χρήστη. Με την εντολή
`input()`, του ζητάμε να το γράψει με το πληκτρολόγιο.

Το πρόγραμμά μας αποθηκεύει την πληροφορία σε μία μεταβλητή.

Μπορούμε να του εμφανίσουμε ένα string για να του πούμε τι πληροφορία θέλουμε να
μας δώσει, μέσα στην παρένθεση.

```python title="Σύνταξη"
answer = input("question")
```

```python title="Παράδειγμα"
name = input("Πώς σε λένε;")
```

Το μήνυμα «Πώς σε λένε;» εμφανίζεται στον χρήστη. Το κείμενο που θα
πληκτρολογήσει ο χρήστης αποθηκεύεται στη μεταβλητή `name` ως **string**.

!!! warning "Προσοχή"
    Ένα string μπορεί να περιέχει οποιονδήποτε χαρακτήρα π.χ. ένα κενό (space) ή
    έναν αριθμό. Η απάντηση του χρήστη αποθηκεύεται **πάντα** ως string.

Αν ξέρουμε ότι η απάντηση θα είναι αριθμός και θέλουμε να τη χρησιμοποιήσουμε σε
πράξεις, πρέπει να τη μετατρέψουμε σε αριθμό μορφής `int` (ακέραιο αριθμό) ή
`float` (δεκαδικό αριθμό).

```python title="Σύνταξη"
age = int(input("How old are you?"))
```
