## Αριθμητικές πράξεις

| Πράξη | Τελεστής | Παράδειγμα | Αποτέλεσμα |
|-------|----------|------------|------------|
| πρόσθεση | `+` | `9+2` | `11` |
| αφαίρεση | `-` | `9-2` | `7` |
| πολλαπλασιασμός | `*` | `9*2` | `18` |
| διαίρεση με δεκαδικό αποτέλεσμα | `/` | `9/2` | `4.5` |
| πηλίκο ακέραιας διαίρεσης | `//` | `9//2` | `4` |
| υπόλοιπο ακέραιας διαίρεσης | `%` | `9%2` | `1` |
| ύψωση σε δύναμη | `**` | `9**2` | `81` |

??? tip "Ψάξε μόνος σου"
    [docs.python.org — αριθμητικές πράξεις](https://docs.python.org/3/reference/expressions.html#binary-arithmetic-operations)

## Προτεραιότητα πράξεων

Η προτεραιότητα πράξεων ισχύει ακριβώς όπως στα μαθηματικά. Δηλαδή:

1. ύψωση αριθμού σε δύναμη
2. πολλαπλασιασμός, διαιρέσεις, πηλίκο
3. πρόσθεση ή αφαίρεση

Ο υπολογισμός γίνεται από τα αριστερά προς τα δεξιά.

Μπορούμε να αλλάξουμε την προτεραιότητα πράξεων με παρενθέσεις `(...)`, ακριβώς
όπως στα μαθηματικά. Αν έχουμε πολλές παρενθέσεις με τη μία μέσα στην άλλη, η
μαθηματική έκφραση που βρίσκεται μέσα στην πιο εσωτερική παρένθεση υπολογίζεται
πρώτη.

## Πράξεις με μεταβλητές

Μπορούμε να αποθηκεύσουμε το αποτέλεσμα πράξεων με μεταβλητές ή αριθμούς σε
μεταβλητή. Μπορούμε επίσης να εμφανίσουμε το αποτέλεσμα πράξεων με αριθμούς ή
μεταβλητές γράφοντάς τις απευθείας μέσα στην `print`.

Παραδείγματα:

```python
print(100%3 + 5)
```

```title="Αποτέλεσμα"
6
```

```python
value = 7//2 * 7
print(value)
```

```title="Αποτέλεσμα"
21
```

```python
print((2**2)**2)
```

```title="Αποτέλεσμα"
16
```

```python
x = 10
x = x*100 + 7*(5+3)
print(x)
```

```title="Αποτέλεσμα"
1056
```

## Πράξεις με strings

| Πράξη | Τελεστής | Παράδειγμα | Αποτέλεσμα |
|-------|----------|------------|------------|
| ένωση string | `+` | `s = 'a' + 'b'` | `s = 'ab'` |
| επανάληψη string | `*` | `s = 3*'a'` | `s = 'aaa'` |

Χειριζόμαστε τις πράξεις με strings όμοια με τις αριθμητικές.

??? tip "Ψάξε μόνος σου"
    [docs.python.org — πράξεις με ακολουθίες (strings)](https://docs.python.org/3/library/stdtypes.html#common-sequence-operations)
